# jithintm.github.io

Personal home page of Jithin Thomas Mathew, hosted with GitHub Pages.

Plain HTML, CSS and a tiny bit of JavaScript. No build step.

## Preview locally

    python3 -m http.server 8000   # then open http://localhost:8000

## Deploy

Repository name must be exactly `jithintm.github.io` (user site).
Push to `main`; then Settings → Pages → Deploy from branch → `main` / root.

## Files

- `index.html`      page content
- `assets/style.css` styles (light and dark theme)
- `assets/main.js`   theme toggle, year, scroll highlight
- `404.html`        not-found page
